# Dragon Ball Character Gallery – Fun Time HTML Project

This is a fun, interactive HTML + CSS + JS project that displays a visual gallery of iconic characters from the **Dragon Ball** universe. Clicking on any image opens it in full-screen mode with navigation controls to browse through all characters.

---

## 🌟 Features

- 📸 Card-style layout featuring characters like Goku, Vegeta, Gohan, and more.
- 🖼️ Fullscreen overlay image viewer with next/prev controls.
- 🔥 Responsive design (mobile-friendly with viewport scaling).
- 🎨 Simple, clean, and fast-loading interface.
